      オフ — 外への通信はしません

      オンにすると位置の許可を求め、約 1 km に丸めた位置でサーバーが 30 分に 1 回天気を問い合わせます。見た目に出るのは、ビルの全景（部屋が 7 つ以上）です。

        通知と、質問の待ち時間

        Mac のシステム設定 → 通知 → Google Chrome をオンにしてください（オフだと通知が出ないまま、質問は viz で待ちます）。

        通知する出来事（このブラウザに覚える）

        待っている間、ターミナルや VS Code には質問が出ません。カードの「ターミナルで答える」でいつでも戻せます。viz のページを全部閉じると、12 秒ほどで戻ります。ページが見えていないときは、質問の通知がオンで許可済みの間だけ待ちます。

        ロボットを呼ぶ

        viz はこのコマンドを実行しません。ターミナルに貼って、自分で実行してください。担当名と役割の文は、それぞれ 1 つの引数として渡ります。
